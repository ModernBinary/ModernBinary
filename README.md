## Key Features of ModernBinary

- **Mentally computable**: Every value is ASCII × position, expressed in binary. you can encode or decode any string by hand with no tools.
- **Built-in commands**: Print, input, and length are available out of the box. No imports, no boilerplate.
- **CLI converter**: Translate any text to ModernBinary encoding or back directly from the terminal with `--texttomb` and `--mbtotext`.
